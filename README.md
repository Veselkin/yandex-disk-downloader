# Yandex Disk downloader

Актуально после того, как Яндекс [отключил бесплатную синхронизацию в десктопном приложении](https://habr.com/ru/news/1042970/) с 3 июня 2026 года.

Проект включает две независимые реализации:

- **Консольный загрузчик (Python)** — для автоматизированного скачивания больших папок и архивов.
- **Графическое приложение (Flutter)** — для Windows и Android с отображением прогресса и возможностью продолжения загрузки.

## Консольный Python-скрипт

Консольный Python-скрипт для надежного скачивания больших публичных папок и одиночных файлов с Яндекс Диска без необходимости авторизации и использования OAuth-токенов. Проект оптимизирован для работы с многотысячными архивами и устойчив к сетевым сбоям, ограничениям скорости и лимитам API.

### Ключевые особенности

- Без авторизации: Работает по стандартным публичным ссылкам (disk.yandex.ru/d/...) без создания приложений и получения токенов.

- Обход лимитов (429 Too Many Requests): Интеллектуальный парсинг заголовка Retry-After, экспоненциальный бэкофф и случайный разброс (jitter) для предотвращения блокировок по IP.

- Пагинация: Корректный обход глубоких и многоуровневых директорий с лимитами порций (по умолчанию по 100 элементов за запрос) для экономии памяти и стабильности.

- Локальное кэширование списка: Сохраняет структуру файлов в персональный JSON-кэш на основе хэша ссылки (с TTL 24 часа), исключая повторные запросы метаданных при перезапусках.

- Мгновенный пропуск недоступных файлов (gone): Если файл возвращает фатальные ошибки (400, 404, 410, 500), скрипт помечает его статус в кэше и не тратит сетевые запросы при последующих запусках.

- Возобновляемая докачка (HTTP Range): Если соединение прервалось, скрипт не скачивает файл заново, а докачивает оставшуюся часть с байта обрыва.

- Контроль целостности (MD5): Сверяет размер и хэш скачанных файлов с метаданными Яндекс Диска.

### Требования
- Python 3.8 или выше (сторонние библиотеки не требуются, используются только встроенные модули).

Можно указать собственную папку назначения:

### Особенности работы при сбоях

- При возникновении временных сетевых ошибок или троттлинга (429) скрипт автоматически выдерживает паузу и повторяет попытку (до 5 раз).

- Ошибки сервера (500 Internal Server Error) или постоянные проблемы доступа (404/410) обрабатываются корректно: после исчерпания попыток файл помечается как gone, а скрипт продолжает работу со следующими элементами.

#### Ошибка 400 (Bad Request — «Плохой запрос»)
Означает баг в логике генерации запроса, файл скачать не удастся.

#### Ошибка 404 (Not Found — «Не найдено»)
Файл или папка физически удалены с сервера Яндекс Диска либо указанный путь (path) ведет в никуда.

#### Ошибка 410 (Gone — «Удалено / Больше не доступно»)
Ресурс существовал ранее, но был окончательно удален владельцем.

#### Ошибка 500 (Internal Server Error - «Внутренняя ошибка сервера»)
Это внутренняя ошибка сервера, и без диагностики её первопричина неизвестна.

При этих ошибках не имеет смысла продолжать повторно делать на них запросы, поэтому им присваивается состояние gone, и при повторном запуске скрипта эти файлы пропускаются (пока действителен TTL кеша).

- Повторный запуск скрипта после сбоя позволяет мгновенно продолжить загрузку с места остановки, пропуская уже проверенные файлы.

## Графическое приложение для Windows и Android

Проект переписан на Flutter с сохранением оригинальной логики и пауз консольного скрипта, с поддержкой платформ Android и Windows. Для платформы Windows portable приложение flutter было упаковано в единый файл .exe с помощью Enigma Virtual Box.

### Возможности

- Скачивание файлов и папок по публичной ссылке Яндекс Диска.

- Рекурсивная загрузка содержимого вложенных папок.

- Выбор папки для сохранения файлов.

- Отображение общего прогресса загрузки и состояния отдельных файлов.

- Сохранение информации о текущей задаче.

- Продолжение загрузки после перезапуска приложения.

- Проверка уже загруженных файлов при восстановлении задачи.

- Проверка целостности загруженных файлов по контрольной сумме MD5, предоставленной Яндекс Диском (если доступна).

- Повторная загрузка при несовпадении контрольной суммы.

- Обработка сетевых ошибок и повторные попытки загрузки.

- Обработка ограничений запросов Яндекса (HTTP 429) с ожиданием перед продолжением.

- Фоновая загрузка на Android с использованием foreground service.


### Установка

Готовые файлы публикуются на странице релизов: **[последний релиз](https://github.com/Veselkin/yandex-disk-downloader/releases/latest)** · [все релизы и список изменений](https://github.com/Veselkin/yandex-disk-downloader/releases)

1. Откройте страницу последнего релиза.
2. В списке **Assets** скачайте файл для своей платформы:

   | Платформа | Файл |
   |---|---|
   | Windows | `yandex-disk-downloader-<версия>.exe` |
   | Android 7.0+ | `yandex-disk-downloader-<версия>.apk` |

3. **Windows:** запустите EXE, установка не требуется.
   **Android:** откройте APK и при необходимости разрешите установку из неизвестных источников.

**Проверка контрольной суммы.** Рядом с файлами лежат файлы контрольных сумм (`.sha1`), а GitHub показывает SHA-1 каждого файла в списке Assets. Проверка в Windows:

```text
certutil -hashfile yandex-disk-downloader-<версия>.exe SHA1
```

### Использование

- Скопируйте публичную ссылку на файл или папку в Яндекс Диске.

- Вставьте ссылку в поле «Публичная ссылка».

- Укажите папку назначения или выберите её через диалог выбора папки.

- Нажмите «Скачать».

- Следите за ходом загрузки в интерфейсе приложения.

- Если загрузка была прервана, приложение сохраняет информацию о задаче. При следующем запуске можно продолжить загрузку кнопкой «Продолжить».

#### Особенности Android

- Для работы с выбранной папкой приложению могут потребоваться разрешения на доступ к файлам.

- Для фоновой загрузки используется Foreground Service. Android отображает системное уведомление о работающей задаче.

## Ограничения

- Работает только с публичными ссылками: `/d/...` для папок и файлов-контейнеров, `/i/...` для отдельных файлов.
- Файлы со своего Яндекс Диска можно скачать, предварительно создав публичную ссылку на нужный файл или каталог.
- Скорость скачивания определяется вашим каналом связи, состоянием серверов Яндекса и лимитами его API. При сбоях проверьте доступность сервисов Яндекса, интернет-канал и уменьшите количество потоков.
