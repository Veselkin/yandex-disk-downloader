# Yandex Disk Downloader

Скачивание публичных папок с Яндекс Диска по ссылке — без авторизации и без платной подписки. Есть приложение с интерфейсом для Windows и Android и консольный скрипт.

Актуально после того, как Яндекс [отключил бесплатную синхронизацию в десктопном приложении](https://habr.com/ru/news/1042970/) с 3 июня 2026 года.

## Приложение Yandex Disk Downloader

* Параллельная закачка: число потоков (1–8) выбирается в списке и меняется прямо во время скачивания
* Общий прогресс и прогресс каждого активного файла
* Пропуск уже скачанных файлов, можно прерывать и продолжать
* Повтор при сетевых сбоях, на каждой попытке запрашивается новая ссылка
* Выбор папки через проводник, последняя папка запоминается
* Кнопка «Очистить» для новой задачи без перезапуска

### Windows

`exe` собран PyInstaller, поэтому SmartScreen или антивирус могут показать предупреждение (ложное срабатывание): «Подробнее → Выполнить в любом случае». Контрольные суммы SHA-256 указаны в описании релиза.

### Android

Папка по умолчанию: `/storage/emulated/0/Download/yadisk`. Если приложение пишет, что нет доступа к папке, включите ему «Доступ ко всем файлам» в настройках Android. APK ставится вне Google Play: разрешите установку из неизвестных источников.

#### Известные ограничения

* При сворачивании приложения Android может приостановить или завершить его процесс. Загрузка в потоке (`asyncio.to_thread()`) на практике может продолжаться некоторое время, но продолжение в фоне не гарантировано.
* Докачки пока нет. Полностью скачанные файлы при повторном запуске пропускаются (проверка по размеру), но недокачанный файл качается заново с начала: в `yadisk_core.py` файл открывается в режиме `"wb"`, а `core.run()` не запоминает смещение.

#### Планы

1. **Докачка файлов.** Если загрузка прервалась, приложение продолжает с последнего сохранённого байта, а не скачивает файл сначала.
2. **Фоновая загрузка.** Android Foreground Service с постоянным уведомлением: загрузка продолжится при сворачивании приложения, насколько это допускает Android. Увеличение таймаутов или правки в `asyncio` эту проблему не решат: нужен именно сервис системного уровня.

### Лимиты Яндекса и количество потоков

У API Яндекс Диска есть ограничение на частоту запросов: порядка 40 запросов в секунду. При превышении сервер отвечает ошибками `429 Too Many Requests` или `403`. Ограничение касается запросов к API (получить список файлов, получить ссылку на скачивание), а не самой передачи данных. На тысячах мелких файлов запросов много, и лимит ощущается острее. При скачивании крупных файлов запросов мало, и лимит почти незаметен.

Приложение держит общий ограничитель: все потоки вместе отправляют в API не больше 20 запросов в секунду, с двукратным запасом до лимита Яндекса. Поэтому **число потоков не влияет на частоту запросов к API и не повышает риск блокировки из-за превышения лимита**: потоки только определяют, сколько файлов качается одновременно. Проверка «файл уже скачан» выполняется на диске и запросов к API не делает. При ответе `429` приложение ждёт время из заголовка `Retry-After` (или нарастающую паузу) и повторяет запрос.

Больше потоков не значит быстрее: скорость обычно упирается в канал. Рекомендуется 3–4 потока.

## Консольный скрипт

Возможности:

* Скачивает всю папку рекурсивно, сохраняя структуру каталогов
* Показывает прогресс каждого файла
* Пропускает уже скачанные файлы (проверка по размеру) — можно прерывать и продолжать
* Автоматически повторяет запрос при таймаутах и сетевых сбоях (с нарастающей паузой)
* Работает с публичными ссылками вида `https://disk.yandex.ru/d/...` и `https://disk.yandex.ru/i/...`
* Только стандартная библиотека Python — ничего устанавливать не нужно

Требования: Python 3.8+

```
python yadisk_downloader.py <ссылка>
```

Файлы сохранятся в папку `downloaded` рядом со скриптом. Можно указать свою папку:

```
python yadisk_downloader.py <ссылка> C:\MyFiles
```

Пример:

```
> python yadisk_downloader.py https://disk.yandex.ru/d/XXXXXXXXXXX D:\Загрузки

Получаю список файлов...
Найдено файлов: 295, общий размер: 1842.3 МБ

[1/295] Фото/01.jpg
  100% (2.1 MB)
[2/295] Фото/02.jpg
  пропускаю (уже скачан)
...
Готово! Файлы сохранены в: D:\Загрузки
```

Скрипт качает файлы последовательно, по одному, поэтому лимит запросов ему практически не мешает.

## Сборка из исходников

```
cd app
python -m venv .venv
.venv\Scripts\activate
pip install flet pyinstaller
flet run src/main.py                               # запуск для отладки
flet build apk                                     # Android (нужны JDK 17, Android SDK и NDK)
flet pack src/main.py --name YandexDiskDownloader  # один exe для Windows
```

Готовый APK появится в `build/apk` под именем проекта, для релиза его переименовывают в `YandexDiskDownloader.apk`.

## Как это работает

Используется официальное публичное API Яндекс Диска (`cloud-api.yandex.net`), авторизация не требуется. Папка обходится рекурсивно, каждый файл скачивается по отдельной прямой ссылке. При таймауте или обрыве соединения запрос повторяется автоматически: скрипт делает до 5 попыток для запросов списка и до 3 для скачивания файла, приложение — до 5 попыток с новой ссылкой на каждой.

## Ограничения

* Работает только с публичными ссылками (`/d/...` для папок и файлов-контейнеров, `/i/...` для файлов)
* Файлы со своего диска можно скачать, если поделиться ссылкой на нужный файл или каталог
* Лимит запросов к API Яндекса описан выше
