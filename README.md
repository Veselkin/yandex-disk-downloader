# Yandex Disk downloader

[![Последний релиз](https://img.shields.io/github/v/release/Veselkin/yandex-disk-downloader)](https://github.com/Veselkin/yandex-disk-downloader/releases/latest)

Скачивание публичных файлов и папок с Яндекс Диска по ссылке — без авторизации и платной подписки.

Проект включает графическое приложение для Windows и Android, а также консольный Python-скрипт.

Актуально после того, как Яндекс [отключил бесплатную синхронизацию в десктопном приложении](https://habr.com/ru/news/1042970/) с 3 июня 2026 года.

## Установка

Готовые файлы публикуются на странице релизов: **[последний релиз](https://github.com/Veselkin/yandex-disk-downloader/releases/latest)** · [все релизы и список изменений](https://github.com/Veselkin/yandex-disk-downloader/releases)

1. Откройте страницу последнего релиза.
2. В списке **Assets** скачайте файл для своей платформы:

   | Платформа | Файл |
   |---|---|
   | Windows | `yandex-disk-downloader-<версия>.exe` |
   | Android 7.0+ | `yandex-disk-downloader-<версия>.apk` |

3. **Windows:** запустите EXE, установка не требуется.
   **Android:** откройте APK и при необходимости разрешите установку из неизвестных источников.

**Проверка контрольной суммы.** Рядом с файлами лежат файлы контрольных сумм (`.sha256` или `.sha1`), а GitHub показывает SHA-256 каждого файла в списке Assets. Проверка в Windows:

```text
certutil -hashfile yandex-disk-downloader-<версия>.exe SHA256
```

## Приложение Yandex Disk downloader

Графическое приложение для скачивания публичных файлов и папок с Яндекс Диска.

### Возможности

- **Параллельная загрузка:** количество потоков (1–8) выбирается в списке и может изменяться непосредственно во время скачивания.
- **Общий прогресс:** отображение общего прогресса загрузки и прогресса каждого активного файла.
- **Повторный запуск без потерь:** уже скачанные файлы пропускаются, поэтому после прерывания можно запустить загрузку повторно.
- **Автоматические повторы:** при сетевых сбоях и тайм-аутах запросы повторяются, на каждой попытке запрашивается новая ссылка.
- **Выбор папки:** папку назначения можно выбрать через проводник, последний выбранный путь сохраняется.
- **Управление загрузкой:** возможность отменить загрузку и очистить список для новой задачи без перезапуска приложения.

### Windows

Исполняемый файл собран с помощью PyInstaller. Windows SmartScreen или антивирус могут показать предупреждение о неизвестном издателе или потенциальной угрозе (ложное срабатывание): «Подробнее → Выполнить в любом случае». Контрольную сумму можно сверить с файлом `.sha256` из релиза.

### Android

Требуется Android 7.0 или новее.

Папка загрузки по умолчанию:

```text
/storage/emulated/0/Download/yadisk
```

Если приложение сообщает об отсутствии доступа к папке, включите разрешение «Доступ ко всем файлам» в настройках Android.

#### Известные ограничения

- **Фоновая загрузка.** При сворачивании приложения Android может приостановить или завершить его процесс. Загрузка в отдельном потоке (`asyncio.to_thread()`) на практике может продолжаться некоторое время, но продолжение работы в фоне не гарантировано.
- **Докачка файлов.** Докачки пока нет. Полностью скачанные файлы при повторном запуске пропускаются (проверка по размеру), но недокачанный файл загружается заново с начала: в `yadisk_core.py` файл открывается в режиме `"wb"`, а `core.run()` не запоминает смещение.

#### Планы развития

1. **Докачка файлов.** Если загрузка прервалась, приложение продолжает с последнего сохранённого байта, а не скачивает файл сначала.
2. **Фоновая загрузка.** Реализация Android Foreground Service с постоянным уведомлением. Это позволит продолжать загрузку при сворачивании приложения, насколько это допускает Android. Простого увеличения тайм-аутов или изменения `asyncio` для этого недостаточно — нужен системный сервис.

### Лимиты Яндекса и количество потоков

У API Яндекс Диска есть ограничение на частоту запросов — около 20-40 запросов в секунду. При превышении сервер отвечает ошибками `429 Too Many Requests` или `403`.

Ограничение касается запросов к API (получение списка файлов и ссылок на скачивание), а не самой передачи данных.

При скачивании тысяч мелких файлов запросов много, поэтому лимит ощущается сильнее. При скачивании крупных файлов запросов значительно меньше, и ограничение практически незаметно.

Приложение использует общий ограничитель: все потоки вместе отправляют в API не более 20 запросов в секунду, с двукратным запасом относительно предполагаемого максимального лимита Яндекса.

Поэтому **количество потоков не влияет на частоту запросов к API и не повышает риск блокировки из-за превышения лимита**. Потоки определяют только количество файлов, скачиваемых одновременно.

Проверка «файл уже скачан» выполняется непосредственно на диске и запросов к API не делает.

При ответе `429` приложение ожидает время, указанное в заголовке `Retry-After`, либо использует нарастающую паузу, после чего повторяет запрос.

Больше потоков не обязательно означает более высокую скорость: обычно ограничением становится пропускная способность интернет-канала.

**Рекомендуемое количество потоков: 3–4.**

## Консольный Python-скрипт

Помимо графического приложения, проект включает консольный скрипт для скачивания публичных файлов и папок.

### Возможности

- Рекурсивное скачивание папок с сохранением структуры каталогов.
- Отображение прогресса каждого файла.
- Пропуск уже скачанных файлов (проверка по размеру) — можно прерывать и продолжать загрузку.
- Автоматические повторные запросы при тайм-аутах и сетевых сбоях с нарастающей паузой.
- Поддержка публичных ссылок вида `https://disk.yandex.ru/d/...` и `https://disk.yandex.ru/i/...`.
- Использование только стандартной библиотеки Python — дополнительные зависимости устанавливать не нужно.

**Требования:** Python 3.8 или новее.

### Запуск

```bash
python yadisk_downloader.py <ссылка>
```

Файлы сохраняются в папку `downloaded` рядом со скриптом.

Можно указать собственную папку назначения:

```bash
python yadisk_downloader.py <ссылка> "C:\MyFiles"
```

### Пример

```text
> python yadisk_downloader.py https://disk.yandex.ru/d/XXXXXXXXXXX "D:\Загрузки"

Получаю список файлов...
Найдено файлов: 295, общий размер: 1842.3 МБ

[1/295] Фото/01.jpg
  100% (2.1 MB)

[2/295] Фото/02.jpg
  пропускаю (уже скачан)

...

Готово! Файлы сохранены в: D:\Загрузки
```

Консольный скрипт скачивает файлы последовательно, по одному, поэтому лимит запросов API практически не мешает работе.

## Сборка из исходников

Для разработки и сборки графического приложения используются Python и Flet.

```bash
cd app

python -m venv .venv
.venv\Scripts\activate

pip install flet pyinstaller

# Запуск для отладки
flet run src/main.py

# Сборка Android (результат в build/apk)
flet build apk

# Сборка Windows: один exe
flet pack src/main.py --name yandex-disk-downloader-<версия> --icon src/assets/icon.png
```

Для Android-сборки необходимы JDK 17, Android SDK и NDK.

## Как это работает

Используется официальное публичное API Яндекс Диска (`cloud-api.yandex.net`), авторизация не требуется.

Папка обходится рекурсивно, каждый файл скачивается по отдельной прямой ссылке.

При тайм-ауте или обрыве соединения запрос автоматически повторяется:

- Консольный скрипт — до 5 попыток для запросов списка файлов и до 3 попыток скачивания файла.
- Графическое приложение — до 5 попыток с получением новой ссылки на каждой попытке.

## Ограничения

- Работает только с публичными ссылками: `/d/...` для папок и файлов-контейнеров, `/i/...` для отдельных файлов.
- Файлы со своего Яндекс Диска можно скачать, предварительно создав публичную ссылку на нужный файл или каталог.
- Скорость скачивания определяется вашим каналом связи, состоянием серверов Яндекса и лимитами его API. При сбоях проверьте доступность сервисов Яндекса, интернет-канал и уменьшите количество потоков.
